# Autopilot — български превод

Умение (skill) за Claude Code, което превръща една продиктувана идея в работещ
проект — в рамките на един разговор, без да ви кара да одобрявате всяка стъпка.

Казвате какво искате. Autopilot записва думите ви като списък с изисквания,
задава само наистина нужните въпроси, пише спецификацията, разбива работата на
таскове, изпълнява ги и накрая сверява готовия проект обратно с първоначалната
задача. През цялото време следите напредъка в табло, което се отваря само.

## Какво го отличава

- **Нищо не изчезва по пътя.** Думите ви стават номериран списък още в началото
  и всеки следващ етап се проверява спрямо него.
- **Вие решавате колко да пита.** Три режима: пълен автопилот, полуавтопилот
  (по подразбиране) и ръчен.
- **Вие решавате колко да домисля.** Три дълбочини: строго по брифа, обичайна
  и задълбочена.
- **Табло на живо.** Етапи, таскове, време, оставаща работа — в един HTML файл,
  който се отваря с двойно щракване.
- **Ключовете остават ваши.** Autopilot никога не иска пароли и токени — работи
  само с имената на променливите, стойностите ги попълвате вие в `.env`.

## Инсталиране

Копирайте папката в директорията за лични умения на Claude Code:

**Windows**
```
%USERPROFILE%\.claude\skills\autopilot
```

**macOS / Linux**
```
~/.claude/skills/autopilot
```

Рестартирайте Claude Code и извикайте умението с `/autopilot`, последвано от
описание на това, което искате да се построи:

```
/autopilot онлайн магазин за керамика
```

По желание добавете режим и дълбочина:

```
/autopilot full deep телеграм бот за заявки за ремонт
```
